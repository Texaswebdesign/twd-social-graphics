# TWD social graphics

Branded 1080x1080 graphics for Texas Web Design's weekly Facebook / Instagram / LinkedIn posts.

- `template/render.py` + `template/logo.png` — the card template (setup: `npm i @fontsource/oswald @fontsource/inter` inside `template/`)
- `YYYY/YYYY-MM-DD-tue.png`, `-thu.png` — each week's graphics, used by Metricool via their raw.githubusercontent.com URLs
